🔑 Gemini API Key 발급 방법

  1. 구글 계정으로 로그인한 상태에서 Google AI Studio 웹사이트에 접속합니다.
  2. 화면 왼쪽 위의 [Get API key] 버튼(또는 중앙의 파란색 버튼)을 클릭합니다.
  3. [Create API key] 버튼을 누릅니다.
  4. 안내 창이 뜨면 [Create API key in new project]를 선택합니다.
  5. 완료 후 화면에 나타나는 긴 문자열(AIzaSy로 시작함)을 [Copy]하여 복사한 뒤, 이 생성기의 API Key 입력란에 붙여넣습니다.
